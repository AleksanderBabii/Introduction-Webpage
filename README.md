# Introduction Webpage

A personal introduction website created to showcase my background, interests, and web development skills. This project serves as a simple portfolio and demonstrates my understanding of HTML, CSS, responsive design, and website deployment using GitHub Pages.

🌐 **Live Website:**
https://aleksanderbabii.github.io/Introduction-Webpage/

---

## About The Project

The Introduction Webpage is a personal website designed to introduce visitors to who I am and what I am passionate about. The website presents information in a clean and accessible format while demonstrating front-end web development fundamentals.

The project was created as part of my learning journey in web development and focuses on building a responsive and visually appealing user experience.

### Goals

* Create a professional online presence
* Practice HTML and CSS development
* Learn Git and GitHub workflows
* Deploy a website using GitHub Pages
* Improve responsive design skills

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/AleksanderBabii/Introduction-Webpage.git
```

### Navigate to the Project

```bash
cd Introduction-Webpage
```

### Run Locally

Simply open the `index.html` file in your preferred web browser.
